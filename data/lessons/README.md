# data/lessons/

Tanórai anyagok (a tanár diasorai, jegyzetei) tantárgyanként: `data/lessons/<tantárgy>/<fájl>.pdf`.
A mappa tartalma nem kerül a gitbe. Feldolgozás a Claude Code-ban: `/lecke <tantárgy> <fájl> [témakör]` –
a parancs csak a fájlban szereplő anyagból ír feladatokat, tételeket, fogalomkártyákat és szabálytár-bővítést a `content/<tantárgy>/` alá.
