# Hivatalos feladatsorok (saját használatra)

Ide másold az Oktatási Hivatal oldaláról (oktatas.hu → Érettségi → Korábbi évek feladatsorai) letöltött anyagokat,
vizsgaidőszakonként és szintenként külön mappába:

```
data/official/2024-majus-emelt/
  e_angol_24maj_fl.pdf      feladatlap
  e_angol_24maj_ut.pdf      javítási-értékelési útmutató
  e_angol_24maj_fl.mp3      hanganyag
```

Utána a Claude Code-ban: `/import-hivatalos 2024-majus-emelt`, majd az appban „Tartalom újratöltése”.

Ennek a mappának a tartalma (ezt a README-t kivéve) a `.gitignore`-ban van, nem kerül verziókezelésbe.
